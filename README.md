# 功课分

一个可直接在浏览器打开的单页功课评分系统，无需安装或服务器。

## 使用

打开 `index.html` 后，可在左上角切换班级，使用「＋班级」增加班级、「－」删除当前班级。学生、功课和成绩按班级分别保存。学生名单支持单个添加，也支持粘贴多行编号和姓名（每行一组）后批量导入；已有班级编号会更新姓名，不会重复新增。新增功课时，序号会自动填入当前班下一个数字，也可以手动修改；章节只需输入数字，系统显示为「第 X 章」，并默认沿用当前班最近一次使用的章节。数据保存在当前浏览器的本机存储中；换浏览器或清除浏览器数据后不会自动同步。功课成绩和章节总表可导出为 CSV。

评分页的「＋ 录入评分」可用学生编号快速录入完整、整齐和订正分数，并更新下方名单。

「其他分数」用于登记小考、测验或自定义分数项目。小考与测验会按当前班自动编号；每项需填写日期，测验另需填写章节备注。输入考卷满分、进成绩单满分及每位学生的考卷得分后，系统按「考卷得分 ÷ 考卷满分 × 进成绩单满分」换算，并在学生查询和成绩单中显示日期、备注、原始分与换算分。

「导出分数」可按当前班选择功课总平均分及各个小考、测验、自定义项目，下载 CSV。文件只包含学生序号、名字和勾选的分数；已录入的考卷分数会以换算后的成绩单分数导出。功课总平均按章节总表的算法计算，未交功课按 0 分。

「学生成绩单」可按当前班编号查询该生所有功课分数及欠交项目；「功课目录」会列出当前班各项功课的序号和名称；「欠功课表」按所选章节每位欠交学生一行，列出其欠缺的练习，并可导出 CSV。

「学生查功课」可让学生输入姓名，查看该姓名对应班级的所有功课成绩和欠交项目。同名学生会同时显示各自班级的记录。

## 学生手机查看

学生查询目前读取老师当前浏览器里的本机资料，适合先在老师设备上预览。网页本身不含云端同步；把 `index.html` 放到静态网页服务后，学生手机只会读到手机自己的本机资料，无法自动看到老师录入的成绩。要让不同设备共享最新记录，需要再连接云端资料库并设置读取权限。当前的姓名查询仅用于试用，知道学生姓名的人可能查看对应记录。

## 评分规则

- 总分 15：准时 5、完整 5、整齐 3、订正 2。
- 布置日期后一星期为默认截止日期；新增时可自行更改。
- 截止日之后每迟 1 个上课日，从准时分扣 0.5 分，准时分最低 0 分。
- 未填写交功课日期时标记「未交」，默认总分为 0；填写交件日期后，准时分自动计算。
- 功课项目记录序号、章节、项目名字、布置日期和截止日期；订正分默认留空并显示「未完成订正」，输入订正分后计为完成，功课卡片显示完成数量，全部学生完成订正后标记「已完成」。
- 「章节总表」按每位学生、每个章节汇总该章节所有练习的平均分；总平均为各章节平均分的平均值，未交练习按 0 分计入。
- 章节总表可导出为 CSV 文件。
- 星期六、星期日及已登记假期不计；登记为补课日的日期会计入迟交日。
- 初始内置霹雳州 2026 公共假期。学校假期、特别假期及后续年份可在「日历调整」手动录入。

## 注意

开斋节、哈芝节等日期可能依官方公告调整。学校假期未必与公共假期相同，使用前请按学校实际校历在「日历调整」中补充或修订日期。
